# Week 4 – Python Functions

This week focuses on the fundamentals of Python functions, including defining functions, using parameters, returning values, and understanding local vs global variables. The exercises reinforce how functions help structure programs into clear, logical sections.

## What I Practised This Week

### Simple Functions
- Writing basic functions using `def`
- Calling functions from the main program
- Returning and printing results
- Using functions to organise simple tasks (e.g., welcome messages, adding numbers)

### Functions with Parameters
- Passing data into functions
- Using parameters to make functions flexible and reusable
- Returning values from functions for further processing

### Local and Global Variables
- Understanding the difference between local and global scope
- Accessing global variables inside functions
- Using global variables to share data between functions when appropriate

### Calling Functions from Other Functions
- Creating functions that perform individual tasks (add, multiply, etc.)
- Writing a function that calls other functions to combine results
- Understanding how functions can build on each other to create more complex behaviour

## Small Project – Student Registration

The small project for Week 4 involved creating a `student_registration()` function that:
- Collects student information using input
- Generates a unique registration ID using a counter
- Prints the collected information and the unique ID

I also practised:
- Returning multiple values from a function as a tuple
- Unpacking returned values into separate variables
- Printing the results outside the function to keep the logic modular

## Software Design Principles Demonstrated

- **Modularity** – Each task is separated into its own function, making the code easier to understand and maintain.
- **Cohesion** – Every function has one clear purpose (e.g., collecting input, performing a calculation).
- **Readability** – Clear naming, spacing, and comments help explain what each part of the program does.
- **Reusability** – Functions such as add, multiply, or registration logic can be reused or extended in future exercises.
- **Maintainability** – Returning values and separating logic into functions makes it easier to update or debug the program.

This week strengthened my understanding of how functions support clean, organised software design.
