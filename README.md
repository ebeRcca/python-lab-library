# python-lab-sessions
Python tasks completed for IT7522 Software Development Fundamentals.

This repository contains python practice for my Level 5 IT certificate.  
Each week focuses on a different programming concept. The code is organised into folders for clarity.

## Repository Structure

  - **Week 4 – Functions**
  - Practice exercises using `def`, parameters, return values, and breaking programs into logical sections.
  - Includes a small project demonstrating multiple functions working together.

- **Week 7 – Object-Oriented Programming (OOP)**
  - Exercises using classes, objects, attributes, and methods.

## Software Design Principles Demonstrated

Across the repository, the code demonstrates:

- **Readability** – clear naming, spacing, and comments.
- **Modularity** – breaking programs into functions and classes.
- **Cohesion** – each function or class performs one clear task.
- **Reusability** – functions and methods that can be reused in different parts of a program.
- **Documentation** – comments inside code and README files explaining the purpose and design.

This repository supports my learning and helps me practise organising code professionally.
